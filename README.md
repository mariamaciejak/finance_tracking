# Finance Tracking 

A simple console-based Java application for tracking personal expenses.

## Features
- Add expenses with category, description, and date
- View all recorded expenses
- Calculate total spending
- Monthly category summaries
- Persistent storage using a text file

## How to Run

1. Compile the program:
   javac Main.java Expense.java

2. Run:
   java Main

## File Storage
Expenses are saved in `expenses.txt` using a pipe-delimited format.

## Example Entry
12.50|Food|Lunch sandwich|2026-02-27
